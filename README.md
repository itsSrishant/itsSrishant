## 🚀 Featured Project

### 🎙️ AI Voice Calling Platform

An end-to-end conversational AI system capable of holding **real-time spoken conversations** while grounding responses in client-provided knowledge.

**Architecture**

`Voice Input → STT → Conversation Manager → RAG → LLM → TTS → Voice Output`

**Built with**

`React` · `Python` · `FastAPI` · `Vite` · `Tailwind CSS` · `PostgreSQL` · `Docker` · `RAG` · `LLMs` 

The system combines **real-time voice processing, conversational intelligence, and knowledge retrieval** into a single application.
